リアルタイム日英翻訳（Gemini 3.5 Live Translate / GitHub Pages / iPhone対応）

【今回の主な変更】
・翻訳を Gemini 3.7 Flash から Gemini 3.5 Live Translate に変更しました。
・「日本語 / English」ボタンで、話す言語を明示的に切り替えます。
  - ボタンが「日本語」：日本語として認識 → 左に日本語、右に英訳
  - ボタンが「English」：英語として認識 → 左に和訳、右に英語
・表の左は必ず日本語、右は必ずEnglishです。
・単語辞書CSVは既存辞書へ追加し、同じ「よみがな」はCSV側で上書きします。
・発話の区切りで自動的に新しい行へ確定します。複数文がまとまった場合も、日本語と英語の文数が一致すれば文単位で行分割します。
・Cloudflare Worker URLは標準設定済みのため、新しい端末でも設定不要です。
・技術的な長いAPIエラーは画面に出さず、利用者向けの日本語メッセージにしました。
・500/502/503/504系の一時エラーは自動再試行します。接続断も最大3回自動再接続します。

【重要：最初にCloudflare Workerの設定が必要】
GitHub PagesにGemini APIキーを置かないため、Cloudflare Workerは「短時間だけ使える一時トークン」の発行だけを担当します。
音声そのものはWorkerを経由せず、iPhone/PCからGemini Live APIへ直接送信します。

【Cloudflare Worker 設定】
1. Cloudflare Dashboardにログインします。
2. Workers & Pages → Create → Worker を作成します。
3. _CloudflareWorker/worker.js の全文をWorkerのコードへ貼り付けてDeployします。
4. Workerの Settings → Variables and Secrets を開きます。
5. Secretとして次を追加します。
   名前：GEMINI_API_KEY
   値：Google AI Studioで取得したGemini APIキー
   ※APIキーはGitHubやHTMLには絶対に記載しません。
6. Worker URL（例：https://realtime-ja-en-token.xxxxx.workers.dev）を控えます。

【GitHub Pagesへ配置】
公開先： https://wkengo.github.io/RealtimeJaEnTranslator/
1. このフォルダの中身を RealtimeJaEnTranslator リポジトリのルートへアップロードします。
2. Settings → Pages → Deploy from a branch
3. Branch: main / Folder: /(root) を選択して保存します。
4. 数分後、公開URLへアクセスします。

【初回使用】
・Cloudflare Worker URLはアプリに標準設定済みです。PC/iPhoneなど端末ごとの接続設定は不要です。
・通常は「接続設定」を触る必要はありません。Worker URLを変更したい場合だけ使用します。
1. 入力言語ボタンが「日本語」なら日本語で、「English」なら英語で話します。
2. 「開始」を押し、マイクを許可します。

【入力言語ボタン】
・「日本語」表示中：日本語音声として認識し、英語へ翻訳。
・ボタンを1回押すと「English」へ変更。英語音声として認識し、日本語へ翻訳。
・録音中に切り替えた場合は、自動的にLive接続を張り直します。
・左列＝日本語、右列＝English は常に固定です。

【単語辞書】
・「よみがな」「表記」の2列です。例：たかえ → 貴恵
・端末ごとのブラウザ内（localStorage）に保存します。
・CSV読込／CSV出力に対応しています。
・CSV読込は既存辞書を消さずに追加します。同じ「よみがな」があればCSV側で上書きします。
・CSV例：
  よみがな,表記
  たかえ,貴恵
  やざき,矢崎
・辞書内容はLive接続開始時に音声認識のカスタム語彙として渡します（最大100語を優先利用）。
・辞書変更後、録音中の場合は次回の再接続から認識へ反映します。

【フィラー除去】
・ON：Smart文字起こしを使用し、言い淀みやフィラーを整理します。
・OFF：できるだけ発話どおりの文字起こしにします。
・日本語側には端末内でも簡易フィラー除去を行います。

【長時間利用】
Live APIのWebSocket接続には時間制限があるため、このアプリは約8分30秒ごとに新しい一時トークンで自動再接続します。
翻訳履歴は端末内に残り、再接続しても表は消えません。

【エラー表示】
・Gemini混雑：分かりやすい日本語表示＋自動再試行
・利用上限：利用上限に達した旨を表示
・APIキー/権限：Cloudflare Worker側設定を確認する旨を表示
・通信断：1秒→2秒→4秒で最大3回自動再接続
・APIの長い技術エラー本文は表には表示しません。

【iPhone】
Safariで公開URLを開き、共有 →「ホーム画面に追加」でアプリ風に利用できます。
Webブラウザの仕様上、初回は必ず利用者が「開始」を押す必要があります。

【構成】
iPhone / PC
  ↓ マイク音声（PCM 16kHz）
Gemini 3.5 Live Translate（直接接続）
  ↑ 一時トークンのみ
Cloudflare Worker
  ↑ Gemini APIキーはWorkerのSecretに保存

Firebase AI Logic / Firebase App Check は今回のLive Translate経路では使用しません。既存Firebase設定は削除しなくても問題ありません。


【重要：index.htmlを直接開いた場合】
このWebアプリはGitHub Pages上で使用します。Windowsでindex.htmlをダブルクリックして開いた場合、
「開始」を押すと公開中のGitHub Pages版へ移動します。
ローカルの file:// ではGemini Liveへの安全な接続を行いません。
